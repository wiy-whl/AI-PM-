# AI 实习生破局指南：如何操盘一个 Cursor 级别的代码生成项目？

在公司里如果被派去做“类 Cursor/Copilot 的代码生成插件”，这是极度硬核且能写出神仙简历的项目。但作为实习生 PM，你既不懂大模型底层训练，又不能亲自上手写 VSCode 插件源码，一旦处理不好，很容易沦为一个只会跑数据的“打杂专员”。

要在这种硬核技术团队中破局，你需要掌握以下三大核心生存法则：

---

## 策略篇：面对 Cursor 级项目，正确的破局切入点在哪？

不要一上来就跟算法团队聊“我们要用多大的模型、微调几次”。类 Cursor 项目的核心壁垒，**70% 在于上下文工程 (Context Engineering)，30% 才是大模型。**

1.  **明确核心场景切分**：
    向你的导师或 leader 确定，目前团队的首要突破口是 **Tab 键代码补全 (Code Completion/FIM)** 还是 **右侧对话框交互 (Chat/Q&A)**？这两者的工程架构完全不同（前者对延迟极度敏感要求 < 200ms，后者对上下文容量极度贪婪）。
2.  **死磕上下文组装 (Context Window Strategy)**：
    Cursor 最牛的地方不是它用了哪个模型，而是它能在浩如烟海的代码库中，精准找到你要修改的那 5 行代码相关的依赖库。
    作为 PM，你要去梳理：我们传给大模型的 Prompt 里，包含了什么？（当前光标代码？最近打开的 5 个文件？LSP 语法树报错？）。**“如何组装发给大模型的包裹”，是 PM 最核心的产品规划。**

---

## 执行篇：作为实习生，怎么干最容易出“高绩效亮点”？

在大佬云集的研发组里，你可以通过**“接管无人愿做的脏活，并把它工程化”**来建立不可替代的价值。

1.  **打爆评测集 (Evaluation Dataset) —— 实习生立足之本**：
    算法团队最头疼的是不知道自己优化的模型在真实场景里到底好不好用。
    *   **你的动作**：拉取内部真实开发者的 git 提交记录（Commit History）。比如提取某人修复了一个空指针异常的 commit。用这个真实案例的 Bug 代码作为“题目”，用正确的修复代码作为“Ground Truth（标准答案）”。
    *   **价值**：建立一套涵盖“补全”、“改 Bug”、“写单测”的自动化评测集。你掌握了评测规则，就掌握了这个产品迭代的裁决权。

2.  **成为 Prompt Engineering 大师**：
    在业务初期，不动算法层，光靠改提示词收益是最大的。
    *   **你的动作**：不断测试如何把用户选中的代码、终端报错信息用更好的 XML 结构 `<error_log>...</error_log>` 喂给大模型。定期出具《Prompt 版本迭代对比报告》。

3.  **坏样本巡检 (Bad Case Analysis)**：
    每天把内测群里员工反馈的“弱智生成结果”都捞出来归类。告诉研发：“今天暴露了 20 个由于没有识别到同目录下子文件而导致生成的幻觉代码，我们需要增加跨文件检索功能。”

---

## 协作篇：深入深水区，如何与高 P 研发打交道？

做代码生成插件，你要面对三波极其难搞的人：大模型算法团队、IDE 插件前端（VSCode/JetBrains）、合规/安全部门。

1.  **对接算法团队 (AI Researchers)**：
    *   **绝对不要**：用口水话提需求（“模型生成的代码太笨了，把它变聪明点”）。
    *   **必须这么做**：带着 Data 和 Bad Case 去。*“昨天上线的新模型，在『跨文件函数调用』这个类目的 Pass@1 评测通过率下降了 15%，这是 3 个典型的出错 Case 日志，请查收。”* 他们会十分尊重你。
2.  **对接 IDE 插件研发团队 (Client Devs)**：
    *   **绝对不要**：催进度（“右下角的聊天框什么时候能切出来？”）。
    *   **必须这么做**：关注极限边界条件。*“大模型如果 15 秒还没吐出代码，UI 上的 Timeout 超时截断怎么表现？”*、*“用户如果不点同意，我们能不能偷偷监听他的键盘击键？”* 帮他们扫清产品交互的逻辑死角。
3.  **对接安全与合规部门 (Compliance/Security) —— 公司的命脉**：
    代码是科技公司最大的资产。把内部代码通过云端发给大模型（如 ChatGPT），极易造成泄密。
    *   **你的动作**：作为 PM，你必须在 PRD 里写明安全脱敏机制。哪些敏感文件（如带 `password` 的配置文件）绝对不上传？如何对代码中的员工姓名/内网 IP 进行混淆 (Obfuscation) 后再调用外部大模型 API？

当你把**“自动化评测集的掌控”**与**“跨部门的安全数据流转把控”**抓在手里，你就不是一个边缘实习生，而是这个项目不可或缺的“作战参谋”。
